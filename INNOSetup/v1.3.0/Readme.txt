-------------------------------
1. OSNOVNA ULOGA PROGRAMA
-------------------------------
CDClub je program koji sluzi za lakse vodjenje CD klubova.
Program podrzava rad sa vise operatera, unos novih CD-ova
i njihovo izdavanje clanovima, stampanje i snimanje liste
CD-ova i clanova, bekapovanje baze.
Pocetna lozinka operatera broj 0 je 'adminloz'. Taj operater
ima potpun pristup svim bazama, tj. on je administrator.

-------------------------------
2. MINIMALNI SISTEMSKI ZAHTEVI
-------------------------------
- Pentium 286+
- Rezolucija od 1024x768 piksela
- 15 MB slobodnog prostora na hard disku
- Mis i tastatura

-------------------------------
3. Instalacija
-------------------------------
Startujte instalacioni fajl i pratite uputstva na ekranu

-------------------------------
4. Deinstalacija
-------------------------------
Program mozete deinstalirati na 2 nacina :
- Kliknite na Start -> Settings -> Control Panel i izaberite Add/Remove Programs. Nadjite CDClub i kliknite na dugme "Remove"
- Kliknite na Start -> Programs -> MarkoSoft -> CDClub i izaberite Uninstall
